Grasp the whole project in one note

graszp is a lightweight solution architecture method for working with an AI assistant.

What it is

A whole project lives in one markdown note, the Solution Architecture Note (SAN). Its fixed outline is distilled from TOGAF, ArchiMate, PRINCE2, Scrum, ITIL and the Microsoft Solutions Framework: why the work matters, who it is for, the plan from business down to technology, the decisions, the delivery, and the sprints.

Every heading stays, even when the answer is "N/A, because…". A considered N/A is a record that the question was asked. The project's size sets how deep each answer goes; the outline stays the same. A weekend project gets one line per heading; a governed project links each heading to a fuller document.

The session loop

Each working session with the AI follows the same loop:

  1. Resume. The AI reads a short resumption note, which points it to the SAN and to any background notes.
  2. Work. Author and AI work through the next step. The AI proposes text; the author edits the SAN. Decisions are logged one line at a time as they happen.
  3. Hand over. At the end, the AI writes a new resumption note: what was done, the current state, decisions, open items, and where to start next time.

The resumption note works like a bootloader: one instruction brings a fresh AI session up to speed. It also doubles as a sprint review.

The SAN template

The template is a single markdown file. Each heading carries a guiding question and a tag showing which method it comes from.

Outline: Envision · Estimate · Promote · Direct · Initiate · Plan (Motivation, Business, Application, Technology, Migration) · Decision · Manage · Deliver · Report · Close.

Tools

  • Obsidian, for a solo practitioner: the notes live as markdown files on your own drive. You edit in Obsidian; the AI assistant reads and writes the same files. Close a note in Obsidian before the AI writes to it.
  • HackMD, for teams: shared, cloud-based reading and editing of the same markdown notes by several people and AI assistants.
  • Any tool that holds markdown and that your AI assistant can reach will do.

Where graszp fits

  • Like arc42, graszp is a fixed outline you fill to the depth the work needs. arc42 documents a software system; graszp runs a piece of work, and the system's architecture is one part of it. A graszp project can link to an arc42 document.
  • Like TOGAF and PRINCE2, graszp uses their vocabulary, but at the scale of one person or a small team, in one note rather than a document set.
  • For AI assistants, the note is written to be the assistant's working context, and the session loop keeps that context current from one session to the next.

graszp is a personal method in daily use, not a standard. This section records how it relates to established methods as of November 2026, and will change as that comparison develops.
